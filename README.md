# Mini Grid Adventure

A lightweight命令行小游戏，玩家在5x5网格中移动，寻找宝藏并避开陷阱。每一步都会显示当前网格和剩余行动次数。

## 开始游戏
1. 确保安装 Python 3.8+。
2. 在仓库根目录运行：

```bash
python3 game.py
```

## 游戏规则
- 使用 `W/A/S/D` 或 `w/a/s/d` 移动。
- `T` 代表陷阱（随机分布），`X` 代表宝藏。
- 每局有 15 次行动机会；踩到陷阱会失去 2 次机会。
- 抵达宝藏获胜，行动耗尽则失败。

## 开发提示
- 核心逻辑位于 `game.py` 的 `GridAdventureGame` 类。
- 你可以调整常量（如网格大小、陷阱数量、行动限制）来定制难度。

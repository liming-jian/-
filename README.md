# 图书管理系统（PHP + SQLite）

一个轻量、带高级质朴界面的图书管理系统。支持用户注册/登录借阅、30 天借阅周期提醒，以及管理员的图书增删改查和借阅查看。默认使用 SQLite，本地即可运行。

## 功能
- 用户注册、登录、退出。
- 借书默认 30 天，临近到期首页喇叭提醒，支持归还。
- 管理员（默认 `admin/admin123`）：新增、编辑、删除图书，查看借阅记录。
- 页面使用柔和霓虹风格，适配移动端。

## 快速开始
1. 安装 PHP 8+（需启用 SQLite 扩展）。
2. 在仓库根目录启动内置服务器：
   ```bash
   php -S 0.0.0.0:8000
   ```
3. 浏览器访问 [http://localhost:8000](http://localhost:8000)。首次启动会自动生成 `data/library.sqlite` 数据库，并创建默认管理员和示例图书。

## 目录结构
- `index.php`：首页与到期提醒。
- `books.php`：图书浏览与借阅。
- `admin.php`：管理员后台，管理馆藏与借阅记录。
- `register.php` / `login.php` / `logout.php`：账号流程。
- `partials/`：头尾布局片段。
- `assets/style.css`：页面主题样式。
- `config.php` / `init.php`：数据库配置、会话与工具方法。

## 备注
- 数据库文件位于 `data/library.sqlite`，可删除后重新初始化。
- 删除图书前需保证没有未归还的借阅记录。
